- **[`docs/`](docs/)** – Hintergrund-Doku: [Memecoin-Grundlagen](docs/memecoin-grundlagen.md), [pump.fun-Mechanik](docs/pumpfun-mechanik.md), [Risiko- & Scam-Checks](docs/risiko-und-scam-checks.md), [Glossar](docs/glossar.md)
